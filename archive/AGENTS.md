# AGENT RULES FOR BARNBUDDY DEVELOPMENT

## GLOBAL PLAYER FOCUS: STRICT 100% ENGLISH POLICY

- **Rule:** ALL player-facing text, UI elements, game dialogues, error toasts, and button labels MUST be written in English.
- **Prohibition:** Do NOT use Vietnamese in any frontend component, modal, game scene, HUD, or notification.
- **Legacy Migration:** Any Vietnamese terms previously introduced (e.g. *Kim Cang Hộ Thể*, *Mảnh Chó*, *Quay Chó*, *Cường Hóa*) have been fully replaced with their official English equivalents (*Divine Aegis Insurance*, *Soul Shards*, *Lucky Pull*, *Soul Forge*).
